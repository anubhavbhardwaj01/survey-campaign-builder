# Survey Campaign Builder

Premium React + TypeScript + Vite + Tailwind survey builder based on the supplied assignment.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Core implementation:
- Single React state source of truth
- Live mobile/desktop preview
- Dynamic questions/options
- Content + Styling tabs
- Thank-you page and media upload
- Reusable controls
- Undo/redo
- Framer Motion micro-interactions
